# SIGA - Sistema de Gestión Académica

Proyecto formativo independiente (Tecnología en Análisis y Desarrollo de Software).
No es una plataforma oficial del SENA ni está integrada a sus sistemas.

Aplicación web para gestionar aprendices, fichas, instructores, sesiones de
formación y asistencia.

## Tecnologías

- Frontend: HTML5, CSS3 y JavaScript nativo
- Backend: Node.js con Express
- Base de datos: PostgreSQL
- Control de versiones: Git y GitHub

## Estado

En desarrollo. Se utilizan únicamente datos ficticios.

## Estructura

- frontend/: páginas, estilos y scripts del navegador
- backend/: API REST (Express)
- database/: migraciones y datos de prueba
- docs/: documentación del proyecto
